Batch Add (CSV)

Fast batch import of product lines from CSV or Excel into Sales, Purchase, Inventory and Manufacturing documents.

What it does

  • Import multiple order or component lines from CSV, XLS, or XLSX.
  • Supports Sales Orders, Purchase Orders, Stock Pickings, and Manufacturing Orders.
  • Uses exact matching for SKU/barcode and fuzzy matching for product names.
  • Displays preview results before adding lines to the document.

Key Benefits

  • Save time on data entry
  • Reduce manual import errors
  • Handle ambiguous product names with guided selection
  • Installable by copying the addon folder into Odoo's addons path

Compatible Documents

  • Sales Order lines
  • Purchase Order lines
  • Stock Picking operations
  • Manufacturing Order components

Installation

Copy the batch_add folder to your Odoo addons directory and install the module from the Apps menu.

No external services are required and no activation key is needed.
